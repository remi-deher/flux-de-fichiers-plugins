# Pack Compression AV1 & VMAF (`vmaf-av1`)

Ensemble prêt à l'emploi pour compresser efficacement en AV1 tout en garantissant une qualité perceptuelle mesurée :
- **Applications** : `ffmpeg`, `ffmpeg-vmaf`, `ab-av1`, `mkvtoolnix`, `mediainfo`, `interpreteurs` ;
- **Plugins** : `essentiel`, `video`, `vmaf` ;
- **Scripts** : `guard-min-size-saving`, `integrity-check-media` ;
- **Flows** : `vmaf-quality-encode`, `smart-av1-encode`.
