# Pack Stack *arr (`arr-stack`)

Installe en une fois les outils, plugins et flows recommandés pour automatiser les imports **Radarr** et **Sonarr** :
- **Applications** : `ffmpeg`, `mkvtoolnix`, `mediainfo` ;
- **Plugins** : `essentiel`, `video`, `audio`, `sous-titres`, `radarr`, `sonarr`, `notifications` ;
- **Flows** : `radarr-media-normalize`, `sonarr-media-normalize`.
