# Pack Sous-titres Pro (`subtitles-pro`)

Tout le nécessaire pour rendre vos sous-titres compatibles Direct Play sans transcodage forcé :
- **Applications** : `mkvtoolnix`, `ffmpeg`, `tesseract`, `alass`, `interpreteurs` ;
- **Plugins** : `essentiel`, `video`, `sous-titres` ;
- **Script** : `integrity-check-media` ;
- **Flows** : `subtitles-pgs-to-srt-mkv`, `clean-subtitles-mkv`.
