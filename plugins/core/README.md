# Plugin Noyau & Contrôle de Flux

Ce plugin fournit les blocs structurels et réseau de base du catalogue :

- `block.core.file-input` : point d'entrée d'un flux (`file-input`).
- `block.core.condition` : aiguillage conditionnel vers les sorties `true` et `false` (`condition`).
- `block.core.webhook` : notification HTTP avec en-têtes chiffrés (`webhook`).
- `block.core.file-output` : bloc terminal marquant le fichier résultat (`file-output`).
