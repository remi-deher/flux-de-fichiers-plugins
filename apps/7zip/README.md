# 7-Zip (`7zip`)

Extraction des archives (7z, RAR, ZIP, TAR…) reçues avant traitement.

Paquet Debian bookworm `7zip` (binaire `7zz`, 7-Zip 26.01). Utilisé par le plugin **Archives** pour extraire les téléchargements avant leur traitement.

Construction : [`build.json`](build.json), publiée par `build-tools.yml` dans la Release immuable `tools-7zip-1.0.0`.
