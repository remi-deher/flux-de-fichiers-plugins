# dovi_tool (Dolby Vision) (`dovi-tool`)

Conversion et réinjection des métadonnées Dolby Vision (RPU) d'un flux HEVC.

Binaire officiel statique (musl) de [quietvoid/dovi_tool](https://github.com/quietvoid/dovi_tool) 2.3.4. Utilisé par le plugin **HDR et Dolby Vision** pour convertir le profil 7 en 8.1 et réinjecter le RPU d'origine après un réencodage.

Construction : [`build.json`](build.json), publiée par `build-tools.yml` dans la Release immuable `tools-dovi-tool-1.0.0`.
