# hdr10plus_tool (HDR10+) (`hdr10plus-tool`)

Extraction et réinjection des métadonnées dynamiques HDR10+ d'un flux HEVC.

Binaire officiel statique (musl) de [quietvoid/hdr10plus_tool](https://github.com/quietvoid/hdr10plus_tool) 1.7.2. Utilisé par le plugin **HDR et Dolby Vision** pour réinjecter les métadonnées HDR10+ d'origine après un réencodage.

Construction : [`build.json`](build.json), publiée par `build-tools.yml` dans la Release immuable `tools-hdr10plus-tool-1.0.0`.
