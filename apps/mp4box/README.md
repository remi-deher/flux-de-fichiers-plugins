# MP4Box (`app.mp4box`)

Outil en ligne de commande développé par le projet open-source **GPAC**, servant de référence mondiale pour le multiplexage, l'optimisation et la manipulation des conteneurs MP4 (ISO Base Media File Format).

## Capacités clés

- **Remuxage sans réencodage** : conversion rapide de flux vidéo/audio compatibles vers le conteneur MP4/M4V/M4A.
- **Optimisation Web / Streaming (`faststart`)** : replacement automatique des métadonnées (atome `moov`) au début du fichier pour permettre la lecture instantanée en streaming sans attendre le téléchargement complet du média.
- **Gestion des pistes et chapitres** : extraction et ajout de pistes audio, sous-titres timed text (`tx3g`) et chapitres MP4.
- **Support multi-architectures** : `x86_64` et `aarch64`.
