# MediaInfo CLI (`app.mediainfo`)

Outil en ligne de commande de référence mondiale pour la lecture et le parsing exhaustif de métadonnées techniques de conteneurs multimédias (MKV, MP4, AVI, MOV, TS, M2TS, WebM, etc.).

## Points forts

- **Profilage complet** : Résolution exacte, framerate réel, débits vidéo/audio, métadonnées de colorimétrie (BT.709, BT.2020), profils HDR10, HDR10+ et Dolby Vision (Profile 5, 7, 8).
- **Inventaire audio & sous-titres** : Nombre de canaux, codecs (TrueHD, Atmos, DTS-HD MA, EAC3, AAC, FLAC), langues et formats de sous-titres.
- **Sortie JSON native** : `mediainfo --Output=JSON <fichier>`.
