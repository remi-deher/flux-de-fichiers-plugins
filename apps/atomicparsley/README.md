# AtomicParsley (`atomicparsley`)

Écriture des tags et jaquettes des fichiers MP4.

Paquet Debian bookworm `atomicparsley`. Utilisé par le plugin **Vidéo** pour écrire les tags MP4 (équivalent de `mkvpropedit` pour Matroska).

Construction : [`build.json`](build.json), publiée par `build-tools.yml` dans la Release immuable `tools-atomicparsley-1.0.0`.
