# Format MP4 : décision requise

Ce dossier conserve uniquement le rappel d'un arbitrage ouvert. Il ne contient
aucune opération FFmpeg, commande à activer ou référence dans un flow.

MKVToolNix est le remuxer validé et produit le MKV de l'exemple. FFmpeg reste
réservé à la fabrication et à l'analyse des médias synthétiques de tests dans le
dépôt applicatif. L'outil et le format de production d'une sortie MP4 nécessitent
une décision utilisateur explicite. Voir la
[note de décision](../../../docs/questions-ouvertes.md).
